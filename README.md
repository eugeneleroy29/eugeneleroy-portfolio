## ✄ Key Technical & Visual Highlights

* **Interactive "Ask Eugene AI" Twin:** Conversational assistant powered by Groq (`groq/compound-mini`) with sub-second inference answering recruiter inquiries on system architecture and product velocity.
* **Ambient Dynamic Lighting:** Mouse-following radial cursor spotlight and drifting aurora gradient mesh on a developer blueprint grid.
* **3D Perspective Spotlight Cards:** Bento grid cards that calculate mouse coordinates in real-time, casting specular reflection and subtle physics-based tilt.
* **Animated Conic Shimmer Borders:** Rotating gradient beams highlighting commercial flagship and AI Twin consoles.
* **Staggered Viewport Scroll-Reveal:** 60FPS fluid swoop-in animations and top scroll progress indicator.
* **Single Source of Truth:** Updating `src/data/portfolioData.ts` dynamically synchronizes UI cards, filters, and AI Twin knowledge embeddings.

## 🏀 Getting Started Locally

### 1. Clone the repository
```bash
git clone https://github.com/eugeneleroy29/eugeneleroy-portfolio.git
cd eugeneleroy-portfolio
```M

### 2. Install dependencies
```bash
npm install
```

##3 3. Configure Environment Variables
Create a .env.local file in the root directory:
```env
GROQ_API_KEY=your_groq_api_key_here
```

### 4. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
